# TeethLink Authentication & Schemas Subsystem (النظام الصغير)

نظام خفيف ومستقل يحتوي **حصرياً** على طبقة المصادقة والتحقق الطبي (Authentication & Medical Questionnaire) ومخططات قاعدة البيانات (Schemas & Diagrams).

## المحتويات:
1. **المصادقة والتسجيل (Authentication):**
   - تسجيل المريض مع الاستبيان الطبي وحساب أعلام الخطورة (Risk Flags).
   - تسجيل طالب طب الأسنان مع التحقق والربط بكود المشرف (Supervisor ID).
   - تسجيل المشرف الأكاديمي مع اختيار القسم الإكلينيكي (Department).
   - اعتماد ورفض الحسابات من قبل الأدمن مع تسجيل سبب الرفض.
   - تسجيل الدخول وإصدار رموز JWT.
2. **مخططات قاعدة البيانات (Schemas & Diagrams):**
   - مخطط نظام المصادقة والسجل الطبي (10 جداول + View).
   - مخطط النظام الجامعي الكامل (24 جدولاً).
   - إمكانية استعراض المخططات التفاعلية بصيغة SVG وتحميل ملفات الـ SQL DDL.

## طريقة التشغيل:
فقط اضغط نقراً مزدوجاً على:
```bat
start-auth-system.bat
```
سيفتح النظام تلقائياً على الرابط:
**http://localhost:5000**

## بيانات تسجيل الدخول التجريبية (Demo Accounts):
- **الأدمن:** `+201000000001` | كلمة المرور: `Admin@12345`
- **المشرف:** `+201000000002` | كلمة المرور: `Supervisor@12345` (كود المشرف: `4`)
- **طالب طب الأسنان:** `+201000000101` | كلمة المرور: `Doctor@12345`
- **المريض:** `+201000000201` | كلمة المرور: `Patient@12345`
